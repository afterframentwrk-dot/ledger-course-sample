# Ledger & Course (sample site)

Portfolio sample website by Isaac Wallace for a fictional High Point, NC masonry and hardscape contractor. **Not a real business.**

The company name, owner, address, phone, license claims, reviews, and project stories are invented for this demo. A search did not turn up an obvious real North Carolina contractor named Ledger & Course.

- **Business:** Ledger & Course — Masonry, patios & hardscapes
- **Phone:** (336) 555-0184 (fictional)
- **Address:** 214 Quarry Post Road, High Point, NC 27260 (fictional street)
- **Service area:** High Point and the Triad (Greensboro, Winston-Salem, Jamestown, Archdale, Thomasville, and nearby towns)

The footer on every page says this is a sample site by Isaac Wallace.

## Pages

- `index.html` — Home
- `services.html` — Services
- `projects.html` — Project gallery
- `about.html` — About the (fictional) crew
- `contact.html` — Contact and free-estimate form

The contact form uses a [FormSubmit](https://formsubmit.co/) action pointed at `demo-sample-not-monitored@example.com`. It is a placeholder. The form itself says it is a demo and will not receive a real reply.

All asset and page links are relative, so the site can be hosted at the root or under a GitHub Pages subpath such as `/contractor-sample/`.

## GitHub upload

The matching upload folder is `/workspace/portfolio/contractor-upload/`. It keeps the same folder structure (`css/`, `fonts/`, `img/`) so relative paths keep working. GitHub’s web uploader can take a folder drag; a flat file picker may flatten the tree and break those paths, so upload the folders rather than picking files one by one if you can.
